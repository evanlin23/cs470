# Historical pilot development data

The 5,000-work pilot and its proposal-path-v2 results are retained for development history. They are not a second current evaluation dataset. The active demo, study and report use `prototype/uiuc_data_scaled.json`, containing the 13,229 retained papers from the 25,000-work collection. The historical filenames of that active capture are preserved for provenance. Its collection is capped and is not a complete campus corpus. Original analysis code is available in Git history before the single-dataset change.
